# Запуск HLS Key Control Utility в Windows

## Перед началом

Для работы необходимы:

- Windows 10 или Windows 11;
- доступ к SQL Server с реестром HLS;
- установленный драйвер Microsoft ODBC Driver 17 или 18 for SQL Server;
- подключённая оптическая головка и её COM-порт;
- файл `.env` с параметрами подключения и ключами HLS, выданный ответственным администратором.

## Первый запуск

1. Распакуйте архив в постоянную папку, например `C:\HLS-Key-Control-Utility`.
2. Скопируйте `.env.example` и переименуйте копию в `.env`.
3. Заполните `.env` действительными параметрами SQL Server и HLS.
4. Запустите `HLS Key Control Utility.exe`.
5. При необходимости дважды щёлкните `create_desktop_shortcut.cmd` — на рабочем столе появится ярлык приложения.

## Важно

- Не передавайте файл `.env` третьим лицам: в нём находятся параметры доступа и криптографические ключи.
- Не перемещайте `.exe` отдельно от папки `_internal`.
- Логи операций сохраняются локально по дням. Excel-выгрузки создаются в выбранной папке.
- При ошибке подключения к SQL Server проверьте доступность сервера, параметры `.env` и установленный ODBC-драйвер.
